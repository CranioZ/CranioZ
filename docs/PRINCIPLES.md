2. Open Source with a Clear LGPD Boundary

## B. Architecture
3. Extensibility by Design
4. Domain Knows No Infrastructure

9. Clinical Semantics Are Explicit

## C. Clinical Quality
10. Consolidated Libraries Before Reinvention
11. Validation Before High-Impact Operations
12. Determinism and Reproducibility
13. Performance Is a Clinical Requirement
14. Clinical Logic Is Explicit and Testable

## D. Engineering Practice
15. Documentation Is Part of the Code
16. One Way to Do Each Thing
17. Errors Are Information, Not Failures
18. Active clinical data should remain GPU-resident whenever repeated rendering or computation makes transfer avoidance beneficial.
