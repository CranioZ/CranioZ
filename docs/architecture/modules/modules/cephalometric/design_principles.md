The cephalometric localization system follows these principles:

1. The template is semantic, not merely visual.
2. Not every template point is a cephalometric landmark.
3. A Cephalometric Point remains a Point with additional semantic meaning.
4. Regions group points and provide a unit of interaction.
5. Connections define the topology of the template.
6. The template resembles an anatomical retopology but is not a generic retopology system.
7. Reference Box reduces the initial search space.
8. VOIs are central to localization, not merely an optimization.
9. Wrapping is regional rather than a single global deformation.
10. A wrapped point is a candidate, not automatically a verified landmark.
11. Sliding is preferred over unrestricted movement when surface adherence is required.
12. Magnetism controls influence; surface constraints control valid position.
13. Magnetism should consider topology as well as geometric proximity.
14. The influence field should be visually represented through a gradient.
15. Verified or protected landmarks should not be displaced unintentionally.
16. AI is a localization provider, not the architectural foundation.
17. Different localization mechanisms should produce the same LandmarkCandidate abstraction.
18. The first template should be authored directly in CranioZ.
19. The template should be stored independently from patient-specific coordinates.
20. A future template editor should operate on the same domain model.
